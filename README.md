# Library Management System

A Python-based Library Management System developed using functions, lists, dictionaries and loops.

## Features

* Add Books
* View Books
* Search Books
* Issue Books
* Return Books
* Delete Books
* Duplicate Book ID Validation

## Technologies Used

* Python

## How to Run

1. Download the project.
2. Open terminal or command prompt.
3. Run:

```bash
python library_management_system.py
```

## Learning Outcomes

* Functions
* Lists
* Dictionaries
* Loops
* Conditional Statements
* CRUD Operations
* Menu Driven Programs
